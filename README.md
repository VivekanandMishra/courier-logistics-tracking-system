# 📦 Courier Logistics Tracking System

A **Java Spring Boot based Courier Logistics Tracking System** developed to manage customers, shipments, delivery agents, warehouses, payments, and shipment tracking.

## 🚀 Features

- 👤 Customer Management
- 🚚 Delivery Agent Management
- 📦 Shipment Management
- 🏭 Warehouse Management
- 💳 Payment Management
- 📍 Tracking History
- 🔄 RESTful APIs
- 🗄️ PostgreSQL Database
- 🌐 HTML, CSS and JavaScript frontend

## 🛠️ Technologies Used

### Backend
- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- REST API
- Maven

### Database
- PostgreSQL
- SQL

### Frontend
- HTML5
- CSS3
- JavaScript

### Tools
- Eclipse
- Postman
- Git
- GitHub
